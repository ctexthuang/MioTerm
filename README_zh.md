# MioTerm

本仓库的中文说明见 [README.md](README.md)。

MioTerm 基于 [ELYTerminal](https://github.com/ELY-Open-Source/ELYTerminal) 二次开发，
保留原作者、MIT 许可证和第三方版权声明。当前开发代码的上游基座为 0.2.3 的
`fdca49a`，已发布的 MioTerm 0.1.0 基于上游 0.2.2，修改版版本号独立管理。

请从 [MioTerm Releases](https://github.com/ctexthuang/MioTerm/releases) 下载本修改版。
上游安装包不包含 MioTerm 的 SSH、SFTP、远程 Git、监控和加密同步功能。
