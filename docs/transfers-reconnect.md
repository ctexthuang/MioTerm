# 传输任务中心与 SSH 断线重连

适用于 MioTerm v0.1.3 及当前工作目录源码；v0.1.2 不包含本次新增功能。

## 运行当前源码

macOS 在项目根目录执行：

```sh
cargo run --offline --locked --release --features gpui_platform/runtime_shaders
```

首次测试建议使用独立配置目录，不会读取你原来的主机与同步配置：

```sh
MIO_TEST_DIR=$(mktemp -d /tmp/mioterm-transfer-test.XXXXXX)
env MIOTERM_CONFIG_DIR="$MIO_TEST_DIR" target/release/elyterminal
```

## 传输任务

1. 从应用的主机列表连接测试 SSH 主机，打开右侧 Files。
2. 上方本地面板与下方远程面板各进入一个测试文件夹。
3. 选择多个小文件，点击上传图标并确认；也可以拖文件到远程区域。
4. 点击 Files 两个窗格之间的双向箭头展开任务列表；再次点击收起。展开时上下文件窗格仍可操作，任务列表可独立滚动。
5. 每个文件或递归文件夹单独排队，显示状态和耗时；悬停任务可查看原主机、源路径、目标和完整错误。
6. 切换本地会话、另一台主机或收起侧栏，再回来查看：任务继续运行。
7. 选择远程文件下载，确认目标本地文件内容正确。
8. 传输较大测试文件时取消，确认状态结束，后面的任务仍可继续。
9. 取消或失败任务的旋转箭头可以从头重试；目标同名部分文件会被覆盖。
10. 清除图标只清除已经结束的记录，不删除文件，不清除运行中或排队任务。

本地窗格右键文件或文件夹可上传，远程窗格右键可下载；右键选中组内的项目
会保留多选，右键其他项目只传该项目。两个窗格之间也可直接拖拽：本地到远程
是上传，远程到本地是下载，目标是对面当前打开的目录。落在列表中的行上也
使用该窗格当前目录；先进入子目录再拖入。拖拽与右键都先确认再写入。

确认后的任务自动展开中间传输区，显示 SFTP 协议、用户名、主机和端口；悬停
通道信息可查看是否复用当前 SSH 连接。手动收起后继续传输，新任务入队会再次
展开。同一窗格内拖动、其他会话或旧目录的拖动不会创建传输任务。

任务中心在本次应用运行期间共享。退出应用会停止任务，重新启动不恢复队列。
最多保留 200 项任务；达到上限后先清理已结束记录。执行前会复查路径类型，
避免排队期间文件变成符号链接后仍继续传输。

当前按完成项数展示整体进度，单项显示活动指示和耗时。没有字节级百分比、
速度、暂停或断点续传。取消或失败可能留下部分文件，重试从头覆盖；不要用
生产文件测试覆盖与取消。执行中仍需系统 OpenSSH 和远端 Python 3/SFTP。

## 手动重连

1. 建立 SSH 连接，在远程进入一个测试目录，给会话重命名。
2. 执行 `exit`，确认停在已断开页面，不会自动新建一条会话。
3. 点击标题栏的重新连接图标，或右键该会话选择重新连接。
4. 会话仍在原来的位置，名称与上次远程目录保留，Files/Git/监控重新跟随。
5. 检查任务中心的失败传输可以在新连接上重试。

重连建立的是新 SSH 会话，不恢复旧终端滚动内容、远程进程或命令执行状态。
不会自动重发断线时输入的命令；需要进程持久化时可在远程自行使用 tmux。

## 自动重连

1. 编辑主机，开启“断线后自动重连”，保存并重新连接。
2. 确保已完成登录，终端提示符与远程目录正常显示。
3. 对专用测试服务器中断网络或终止对应的服务端连接，避免影响生产连接。
4. SSH 检测到连接丢失、以 255 退出后，显示重连状态并尝试重新建立连接。
5. 恢复网络后检查重连成功，仍使用原会话位置、名称和远程目录。
6. 持续断开时最多尝试五次，等待依次为 2、5、10、20、30 秒。
7. 等待时标题栏停止图标可停止本会话自动重试；关闭会话也会取消等待。
8. 正常 `exit`、初次登录失败和本地终端都不进入自动重试。

自动重连默认关闭，是本机偏好，不随云端主机同步。它依赖 SSH 保活发现断线；
默认保活为 30 秒、连续三次无响应后断开，网络黑洞不会立即触发重连。
自动尝试严格验证主机指纹，并使用已保存凭据、Agent 或非交互密钥；只在旧
终端里手动输入的密码无法自动复用。每次尝试连接超时为 5 秒。
停止本会话重试不修改已保存主机的开关，下次从主机列表连接仍使用保存值。

## 会话状态动画

原来的 3×3 状态点动画保留在左侧“会话”页，展开左栏后点终端图标查看。
连接中显示涟漪，等待自动重连时显示双闪；已断开时不再沿用旧程序的工作状态。
登录成功后，继续显示程序通过 OSC 7501、OSC 9;4 或 herdr 报告的原有动画。
普通命令没有报告状态时，不会凭空显示“工作中”。左右侧栏仍默认关闭。

在本地或远程 zsh/bash 中执行下列命令，可查看约 8 秒的工作动画：

```sh
printf '\033]9;4;3\007'; sleep 8; printf '\033]9;4;0\007'
```

如果当前程序已经启用了 OSC 7501，OSC 9;4 会按协议被忽略，请另开会话测试。
